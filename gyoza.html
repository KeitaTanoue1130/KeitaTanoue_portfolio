ふくおか餃子FES LP制作

餃子イベントに興味を持ったユーザーが、開催情報や出店情報を分かりやすく確認できるLPを制作しました。

制作概要

制作背景
職業訓練校のグループ制作課題として、架空イベント「ふくおか餃子FES」のLPを制作しました。 開催情報や出店情報が分散している想定に対し、公式情報源として分かりやすく情報を整理することを目的としました。
ターゲット
Instagramでイベント情報を収集し、恋人や友人と外出を楽しむ20代女性を中心に想定しました。 餃子好きの彼氏と週末のデート先を探す流れをペルソナとして設定しています。
担当範囲
コーディング / レスポンシブ対応
制作形式
グループ制作
使用技術
HTML / CSS / JavaScript

工夫した点

ターゲットに対する工夫

Instagramでイベント情報を見つけたユーザーが、開催日時・出店情報・アクセス情報をすぐに確認できるよう、 ページ構成を「イベント概要」「出店一覧」「会場MAP」「アクセス」「FAQ」「お問い合わせ」の順に整理しました。

デザイン面での工夫

インパクトのある餃子の写真と、赤・黄・オレンジ系の明るい色合いを使用し、 食欲やイベントのにぎやかさが伝わるデザインを意識しました。 また、おしゃれ好きのペルソナにも受け入れられるよう、ポップになりすぎないバランスを意識しています。

コーディング面での工夫

グループで作成したデザインカンプをもとにコーディングを担当しました。 余白や各セクションの統一感を意識し、情報が整理されて見やすく、快適に閲覧できるサイトを目指しました。

レスポンシブ対応での工夫

PC版ではファーストビュー直下にナビゲーションを配置し、モバイル版ではハンバーガーメニューを設置しました。 ユーザーが知りたい情報へすぐアクセスできるよう、画面幅に応じた導線設計を意識しています。

今なら改善したい点

現在なら、出店店舗ごとの魅力やおすすめメニューをさらに詳しく見せ、 来場前から「食べたい」と感じてもらえるコンテンツを強化したいです。 また、CTAとしてSNS共有や来場予定につながる導線を追加し、 イベント参加への行動をより促せる構成に改善したいと考えています。

制作で学んだこと

最初にペルソナやサイトの色味をチームで決めることで、 全体の方向性を共有しながら制作を進められることを学びました。 また、グループ制作では役割分担だけでなく、意見交換をしながら統一感のあるページに仕上げることが重要だと感じました。
