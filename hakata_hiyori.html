AI Workflow Case Study

博多ひより 食品ギフトEC LP

AI活用による短時間Web制作

Codexへ目的・構成・デザインの方向性を指示し、コードを直接記述せず、 約2時間で食品ギフトECのランディングページを制作した実証作品です。

Project Overview

Project Overview

本作品は、生成AIのCodexを活用し、少ない人的リソースと短い制作時間でWebサイトを構築するワークフローを検証したものです。本人はコードを直接記述せず、サイトの目的、構成、デザインの方向性をCodexへ指示し、生成結果を確認しながら約2時間で完成させました。

AIによる実装を待つ間には別の作業も進められるため、人が制作作業へ拘束される時間を抑えながら、一定品質のWebサイトを形にできる可能性を確認しました。

単なる自動生成ではなく、目的と要件をAIへ伝え、確認と追加指示を重ねて成果物として完成させる「AIディレクション」と制作効率化をテーマにしています。

Project Goals

制作目的

  • 生成AIをWeb制作へ活用した場合の制作速度を検証する
  • 本人がコードを直接記述しない制作フローを試す
  • 人が制作作業へ拘束される時間を抑える
  • 少ない人的リソースで一定品質のサイトを制作する
  • AIへ適切な指示を与え、成果物を完成まで導く力を示す

Workflow

AI活用の制作フロー

  1. 目的と方向性を決定

    食品ギフトECのランディングページとして、サイトの目的と目指す方向性を整理しました。

  2. Codexへ要件を指示

    必要な構成、掲載内容、デザインイメージを言語化して伝えました。

  3. HTML・CSS・JavaScriptを実装

    Codexが要件にもとづいて各ファイルを生成・実装しました。

  4. ブラウザーで結果を確認

    生成されたページを確認し、意図との違いや修正が必要な箇所を整理しました。

  5. 追加指示を行い完成

    必要な修正内容をCodexへ伝え、生成結果を確認しながら完成まで進行しました。

What This Project Demonstrates

この作品で示したこと

  • コードを直接入力せず制作本人が要件と方向性を示し、Codexへの指示によって実装しました。
  • 約2時間で初期版を完成短時間で食品ギフトECのLPを形にする制作フローを実証しました。
  • 拘束時間を抑えた進行AIの実装中には、本人が別の作業へ時間を使うことができました。
  • 少ない人的リソースで制作実装作業をAIへ任せ、確認と判断に人の時間を配分しました。
  • AIディレクション目的や要件を言語化し、追加指示によって完成まで制作を進行しました。
