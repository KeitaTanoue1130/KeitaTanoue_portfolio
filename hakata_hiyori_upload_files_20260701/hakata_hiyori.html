博多ひより 食品ギフトEC LP

福岡のEC企業への応募を想定し、架空ブランド「博多ひより」の博多しめんたいギフトLPを制作しました。 地域商材の魅力、ギフト需要、購入前の不安解消、スマホでの購入導線を意識したEC改善提案型の作品です。

制作概要

目的
福岡のEC・通販系企業に向けて、商品訴求と購入導線を考えたLP制作ができることを示すため。
想定商材
博多しめんたいギフト / 税込4,980円 / 送料無料 / のし対応 / 冷凍配送
使用技術
HTML / CSS / JavaScript / 生成AIによる商品画像作成
実装機能
商品タブ、レビュー絞り込み、数量変更、合計金額表示、FAQ、カート追加風モーダル

課題設定

01 Target

福岡らしいギフトを探す人

お中元、内祝い、帰省土産など、失敗しにくい地域食品ギフトをスマホで探すユーザーを想定しました。

02 Concern

食品ECの不安を減らす

配送、保存方法、賞味期限、辛さ、ギフト対応など、購入前に気になる情報を先回りして整理しました。

03 Action

購入まで迷わせない

価格、数量、合計金額、カート追加を近くに配置し、スマホでも行動しやすい導線を意識しました。

工夫した点

親しみやすい福岡感

高級感に寄せすぎず、家庭の食卓や季節の贈り物を想像しやすい色・写真・コピーにしました。

ECらしい判断材料

レビュー、配送情報、FAQ、ギフト対応を配置し、購入前の比較・検討に必要な情報をまとめています。

JavaScriptで購買体験を表現

数量変更、合計金額表示、商品切り替え、レビュー絞り込みを実装し、静的LPでもECの体験を見せています。

AI活用

商品企画、ターゲット整理、訴求軸、LP構成、コピー、商品画像生成、実装補助にAIを活用しました。 単に画像を作るだけでなく、ECサイトで必要な情報設計を短時間で形にすることを目的にしています。
