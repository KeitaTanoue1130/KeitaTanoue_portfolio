Portfolio Improvement Project

Ongoing Project

公開したポートフォリオを「制作して終わり」にせず、 閲覧データやユーザー行動を分析しながら継続的に改善していくケーススタディです。

Project Overview

Project Overview

このプロジェクトでは、公開済みのポートフォリオを実際に運用しながら、 アクセス解析、SEO、UI・UXの観点から継続的な改善を行います。

完成した制作物を掲載するだけではなく、課題の発見、仮説の設定、施策の実施、結果の確認、次の改善までを記録し、 WebディレクションやWebマーケティングの実務につながる経験として蓄積していきます。

Project Goals

Project Goals

このプロジェクトの中心となる目標は、次の2点です。

Goal 01

企業目線でポートフォリオを改善する

応募先企業へURLを共有した後のアクセス傾向や閲覧ページを分析し、 企業が関心を持つコンテンツや導線を継続的に改善していきます。

Goal 02

外部からポートフォリオへの流入を増やす

Google検索やSNSなどからの訪問を増やすため、 SEO、GA4による分析、コンテンツ改善を継続的に行います。

GA4で企業や個人を特定するのではなく、URLを共有した時期とアクセス状況を照合し、閲覧傾向を分析します。

Vol.01

GA4による計測環境の構築

日付
2026.07.22
カテゴリー
Analytics

課題・目的

これまでは応募先企業へポートフォリオのURLを送付しても、実際にページが閲覧されたのか、 どのページが見られたのか、どのような経路で訪問されたのかを客観的に確認できませんでした。

今後の改善を感覚だけで判断しないため、まずアクセスデータを収集できる環境を整えることを目的としました。

実施内容

  • Google Analytics 4をポートフォリオへ導入
  • 計測タグが各ページで正しく読み込まれているか確認
  • リアルタイム計測を利用してアクセスが記録されることを確認
  • 今後の改善効果を比較するための計測基盤を構築

結果

ポートフォリオへのアクセスをGA4で計測できる状態になりました。

現時点ではデータ量が少ないため、具体的な改善判断を行う段階ではありませんが、 今後のアクセス数、流入経路、閲覧ページ、ユーザー行動を確認するための土台を構築できました。

学び・考察

Webサイトを改善するためには、デザインや文章を変更する前に、現在の状態を把握できる計測環境が必要です。 今後は推測だけで変更するのではなく、取得したデータと改善目的を結びつけながら施策を検討します。

Next Action

  • 応募先企業へURLを共有した後のアクセス状況を確認する
  • 閲覧されたページや流入経路を確認する
  • データを一定期間蓄積する
  • 得られた傾向をもとに、最初のUI・UX改善を実施する
