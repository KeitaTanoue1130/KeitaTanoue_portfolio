旅館 琥珀 公式Webサイト

職業訓練のグループ課題として、雪国にある架空の温泉旅館「旅館 琥珀」の公式サイトを制作しました。 コンペ形式の課題で、私は6人チーム「Ricca」のリーダーとして企画・デザイン・コーディング・レスポンシブ対応を担当しました。

制作概要

制作形態
職業訓練のコンペ課題・6人でのグループ制作（チーム「Ricca」）
担当
リーダー、企画、情報設計、Webデザイン、HTML / CSS / JavaScript実装、レスポンシブ対応
使用技術
HTML / CSS / JavaScript / Codex / GitHub Pages
制作期間
2026年6月〜7月

ターゲットと課題

01 Persona

幼い子どもがいる30代夫婦

3歳と0歳の子どもがいる30代夫婦をペルソナに設定し、家族全員が安心して滞在できる旅館として訴求しました。

02 Access

雪国への移動の不安を減らす

アクセスが難しそうに見える立地に対し、送迎や交通案内を分かりやすく示し、実際には無理なく訪れられることを伝える設計にしました。

03 Season

冬以外の宿泊需要をつくる

雪景色だけでなく、料理、温泉、客室、家族向けサービスを見せることで、季節を問わず選ばれる旅館を目指しました。

担当と工夫

制作全体をリード

6人のチームで全員の意見を取り入れながら、リーダーとして方向性とスケジュールを整理しました。素材準備はメンバーに依頼し、私はデザインと実装を中心に進めました。

期限内に品質を確保

限られた制作期間の中で、優先順位を判断し、プレゼンに耐えられる最低限の品質を確実に完成させることを重視しました。

レスポンシブまで一貫して担当

トップ、温泉、料理、客室の各ページを実装し、PCとスマートフォンで画像・縦書き見出し・ナビゲーションが適切に見えるよう調整しました。

チーム制作

リーダー、サブリーダー、デザイン、動画、コーディング、プレゼンの役割を置いた6人チームでした。 今回は動画を使用しなかったため、役割を固定しすぎず、全員で意見を出し合いながら進行しました。 チーム制作は3回目で、過去の反省を活かし、大きな問題なく協力して完成へ進めることができました。

AI活用

コーディングの大部分でCodexを活用し、HTML / CSS / JavaScriptの実装、レスポンシブ調整、表示上の問題整理を行いました。 その一方で、今後はCodexを補助として使い、自分自身が実装の中心を担えるようコーディング力を高めることを課題としています。
