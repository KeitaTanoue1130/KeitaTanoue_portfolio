旅館こはく 公式Webサイト

山あいの温泉旅館を想定し、家族で過ごす時間と和の情緒が伝わる公式サイトをグループで制作しました。 温泉・料理・客室の魅力を写真で見せながら、宿泊予約へ迷わず進める情報設計と、PC・スマートフォン双方での閲覧体験を意識しています。

制作概要

制作形態
架空案件・グループ制作（チームA「リッカ」）
担当
フロントエンド実装、レスポンシブ調整、画面検証、UIの仕上げ
使用技術
HTML / CSS / JavaScript / GitHub Pages
制作期間
2026年6月〜7月

サイト設計

01 Atmosphere

旅館らしい情緒を伝える

和紙の質感、落ち着いた配色、縦書きの見出し、大きな写真を組み合わせ、静かで上質な滞在を想像できる世界観を整えました。

02 Information

検討材料を整理する

温泉、料理、客室、子ども向け設備、アクセスをトップページから把握できる構成にし、各下層ページで詳しく確認できるようにしました。

03 Conversion

予約まで迷わせない

予約ボタンと旅行予約サイトへの導線を視認しやすく配置し、スマートフォンでも必要な情報と予約手段へすぐ移動できるよう調整しました。

工夫した点

写真を主役にしたレイアウト

画像の重なりと余白にリズムをつけ、温泉・料理・客室それぞれの魅力が印象に残る画面構成にしました。

PC・スマホの個別最適化

単純な縮小ではなく、画面幅に応じて画像、縦書き見出し、文章、ナビゲーションの配置を調整しています。

複数ページの一貫性

トップ、温泉、料理、客室の4ページで、ヘッダー、背景、見出し、ボタンのトーンを揃えました。

AI活用

実装のたたき台、CSS調整、レスポンシブ表示の問題整理、動作確認の補助にCodexを活用しました。 デザイン意図と変更範囲を具体的に伝えながら、既存構造を保った小さな修正を重ね、短期間で完成度を高めています。
