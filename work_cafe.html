カフェサイト制作

女性ユーザーをターゲットに、居心地の良さと導線設計を意識したカフェサイトを制作しました。

制作概要

制作背景
職業訓練校の課題として、デザインカンプをもとにカフェサイトを制作しました。
ターゲット
20〜30代女性。落ち着いた空間でゆっくり過ごしたい人を想定しています。
担当範囲
コーディング / レスポンシブ対応
制作期間
約1日
使用技術
HTML / CSS

工夫した点

ターゲットに対する工夫

落ち着いた雰囲気を好むユーザーを想定し、余白を広めに取り、写真を大きく見せることで ゆったりとしたカフェの空気感が伝わるように意識しました。

デザイン面での工夫

ブラウンやグリーンを基調に、自然で温かみのある印象になるよう配色しました。 また、セクションごとに余白を設け、情報が読みやすくなるよう調整しています。

今なら改善したい点

現在なら、予約やメニュー確認への導線をより分かりやすくし、 ボタン配置やファーストビュー内の訴求をさらに強化したいと考えています。
